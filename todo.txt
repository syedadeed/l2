JWT
    iss(Issuer => who created the token) => app name(string) or a URI
    sub(Subject => who the token is about) => user UUID
    aud(Audience => who should accept the token) => list of names(string) or URI, usually not necessary unless you have microservices
    exp(Expiration Time => when does this token stop being valid) => seconds since Unix epoch
    nbf(Not Before => don't accept before this time) => seconds since Unix epoch, usually not necessary
    iat(Issued At => time at which the JWT was issued) => seconds since Unix epoch
        iat must be between nbf and exp to be ensure the validity of the jwt
    jti(JWT ID => unique ID for the token itself) => UUID, usually not necessary
